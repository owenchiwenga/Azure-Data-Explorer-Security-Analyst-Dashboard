# Azure Data Explorer – Security Analysis Dashboard

## Project Overview
This project demonstrates how Azure Data Explorer (ADX) can be used to ingest, analyze, and investigate security logs using Kusto Query Language (KQL).

## Objectives
- Generate a sample authentication log dataset.
- Ingest security logs into Azure Data Explorer.
- Detect suspicious login activities.
- Investigate failed authentication attempts.
- Identify potentially compromised accounts and suspicious IP addresses.
- Develop security monitoring queries and dashboards.

## Technologies
- Microsoft Azure Data Explorer
- Kusto Query Language (KQL)
- GitHub
- CSV Security Log Dataset
